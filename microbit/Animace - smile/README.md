Animace – Smile

Jednoduchý ukázkový program pro micro:bit vytvořený v prostředí Microsoft MakeCode.

Animace pracuje s ručně zadanými souřadnicemi LED bodů a slouží jako úvodní příklad
pro pochopení práce s displejem micro:bitu, časováním (čekej) a událostmi
(stisk tlačítek).

Projekt je určen jako inspirační ukázka pro žáky při návrhu vlastní animace.

Odkaz na repozitář MakeCode https://github.com/marketaklvanova/animace-1
