Animace – Pohyb po obvodu

Ukázkový program pro micro:bit vytvořený v prostředí Microsoft MakeCode.

Program zobrazuje blikající LED bod, který se pohybuje po obvodu displeje.
Poloha bodu je řízena proměnnými x a y, směr pohybu je určen stavovou proměnnou.
Rychlost animace lze měnit pomocí tlačítek zařízení.

Projekt slouží jako učitelská ukázka práce s proměnnými, podmínkami a cyklem
a jako základ pro tvorbu vlastní animace žáků.
